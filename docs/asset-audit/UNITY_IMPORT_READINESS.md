# Roofline Relay — Unity Asset Import Readiness & Staging Recommendations

## 1. Executive Context & Scope
This document provides a technical readiness evaluation for importing 3D assets from the Roofline Relay asset audit library (`docs/asset-audit/organized-models/`) into the newly initialized Unity 6 project (`unity-game/Assets/Art/`).

- **Master Model Inventory:** 44 verified `.glb` assets cataloged across 5 categories.
- **Target Engine:** Unity 6 (`6000.6.7f1`) with Universal Render Pipeline (URP).
- **Target Hardware Constraint:** Standard laptop with 8 GB RAM and integrated Intel UHD Graphics. Target frame rate: 60 FPS on Windows desktop, 30–60 FPS on Android mobile (landscape orientation).
- **Import Strategy:** Phased and selective. Do **not** import or duplicate all 44 models at once. High-density meshes and unrigged raw geometry must undergo retopology and decimation prior to inclusion in the active runtime hierarchy.

### 3.2 Dimensional & Pivot Discrepancies

1. **`AUDIT_MDL_02` (Courier Candidate A):** Height is 2.700m (giant proportions). Rescale to 1.85m in import settings (`Scale Factor = 0.685`).
2. **`AUDIT_MDL_14` (Amber Core Data Shard):** Model is 1.899m × 1.133m × 0.337m (size of a refrigerator). For a collectible floating pickup, the prefab should be scaled down to ~0.35m height (`Scale Factor = 0.20`).
3. **`AUDIT_MDL_23` (Water Storage Tank):** Total height is currently 1.000m. A real industrial rooftop tank with structural stilts is 3.5m–5.0m tall. Must be scaled up 3.5× in Unity.
4. **`AUDIT_MDL_39` (Metal Service Door):** Height is 1.000m (half-height door). Real exterior service doors are 2.10m high. Requires 2.1× vertical scaling and pivot alignment along the frame threshold.

## 5. Unity Asset Pipeline & Material Guidelines

When importing models into `unity-game/Assets/Art/`:

1. **Model Tab Settings:**
   - **Mesh Compression:** Set to `Medium` for environment modules, `Off` for rigged characters.
   - **Read/Write:** Disable unless vertex access is strictly needed by a procedural system (saves 50% CPU RAM).
   - **Generate Colliders:** Uncheck automatic mesh colliders. Use primitive `BoxCollider` or `CapsuleCollider` components on parent GameObjects for peak performance.
   - **Normals:** Import normals; calculate tangents with MikkTSpace.
2. **Rig Tab Settings:**
   - Characters: Animation Type = `Humanoid`. Configure avatar and verify bone mappings.
   - Static Props & Architecture: Animation Type = `None`.
3. **Materials Tab Settings:**
   - Extract embedded materials and textures into `Assets/Art/Materials/` and `Assets/Art/Textures/`.
   - Ensure all materials use the URP Lit or URP Simple Lit shader. Use Simple Lit for mobile / low-end performance targets where specular highlights and basic normal maps suffice.
