# Roofline Relay

**Roofline Relay** is an original 3D rooftop parkour game designed for fluid momentum-based traversal across dense urban skylines, targeting landscape-oriented mobile play and desktop platforms.

---

## Project Overview

- **Genre:** 3D Rooftop Parkour / Momentum Traversal / Time-Trial Runner
- **Target Platforms:** Landscape Mobile (iOS / Android) and Desktop (PC)
- **Art Direction:** Stylized industrial realism featuring high-contrast rooftops, modular architecture, mechanical hazards, and clear traversal readability.
- **Repository Purpose:** This repository serves as the official source-control home for Roofline Relay, encompassing all core documentation, design specifications, asset manifests, production reference libraries, and organized 3D models.

> **Note:** Game engine project initialization and gameplay implementation are scheduled for subsequent milestones.
